# RStudy

RStudy è un servizio web per organizzare lo studio per corsi e lezioni e lavorare sui propri appunti in modo attivo:
riepiloghi, esercizi, flashcard, schemi e reel generati dall'AI, domande sui materiali del corso.
In produzione su [rstudy.dev](https://rstudy.dev).

Il codice è in [`saas/`](saas/): avvio locale, produzione, test e variabili sono descritti in [`saas/README.md`](saas/README.md).

L'app desktop (Electron) e il vecchio sito sono stati rimossi; restano nella cronologia git.
Chi usava il desktop può importarne il backup JSON dalle Impostazioni di RStudy.
