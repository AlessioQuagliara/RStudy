# Admin dashboard

Thank you for purchasing this page. I hope it's going to be helpful for you.

## Features

- HTML admin dashboard layout made with daisyUI 5
- Framework agnostic. Can be used everywhere
- No dependencies

## Including

- 100 dashboard pages with every possible UI blocks needed for a dashboard
- 2 exclusive daisyUI themes (dark/light)
- Charts, tables, cards, forms, dropdowns, and more.

## Preview the built output:

```
npx -y serve public
```

## build from src

1. Install dependencies

```
npm install
```

2. Run the dev server

```
npm run dev
```
